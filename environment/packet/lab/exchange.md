# 协调发布的交换政策

清单是 UTF-8 TSV，表头 source、path，按行排列来源优先级。来源标识唯一；相对路径相对于清单目录。source 和请求样本名为非空 ASCII 标识，不含逗号或空白。请求样本名称互不重复，每个名称须至少存在于一个来源标题。各源内部的物理记录序号从0开始，排序或协调后不得重编这些序号。

交换输入保留 VCF4.3/BCF2.2 的标题、单条记录及 FORMAT 表示，但不保证记录顺序：位置可倒退，染色体可重新出现，同位置的记录可相隔很远。它们是无序交换流，不要求可建立 VCF/BCF 索引。输入可以是未压缩文本、BGZF VCF 或 BCF，不支持实时管道、URL、其他压缩格式。标题与字段声明完整，源记录按声明具有正确基数；GT 下标引用该源字典。

接收报告按染色体名称 UTF-8 字节顺序、数值位置排序，每个 (CHROM,POS) 只发布一行。先协调该位置的参考跨度：取该位置所有源记录中最长的 REF；每个较短 REF 必须是最长 REF 的精确前缀，否则整次发布失败。同长度但内容不同也失败。补齐较短表示时，REF 和每个 ALT 后附最长 REF 中未被该源 REF 覆盖的后缀；不能只改 REF、保持 ALT 原字面字符串。这个协调仅作用于同一 CHROM/POS，不做左对齐、跨位置归并或外部参考查询。N 是字面碱基，不是通配符。

发布字典的 REF 是协调后的最长 REF，ALT 包含该位置全部源记录协调后 ALT 的去重并集；包含未获基因型判定及非主要观测的记录。ALT 内部排列自由，但所有观测必须与实际发布字典配套。观测中的等位身份以协调后的字符串为准：来源数字下标不能作为跨记录身份。未测到的等位或基因型槽位仍是未观测，不允许用0填充。

每个请求样本的 winner 是该位置实际带有这个命名样本的最高优先级来源中的最早物理记录，不以读取、排序、参考长度或 GT 是否缺失改变优先级。others 完整保留其余实际存在的观测；contributors 包含该位置所有源记录。内容相同的重复记录也保留各自 source/ordinal。来源没有这个样本才是缺席；GT 缺失不是撤销测量。该位置无此样本时 winner 为 null、others 为空列表。

来源字段是 GT、AD、PL、DP、GQ、PS，Integer 测量；每个样本含 GT 声明1至4倍体，允许部分和完全缺失。字段以 VCF4.3/BCF2.2 中的等位和基因型含义解释；相位分隔符及带相位的等位访问顺序保留。完全未相位的 GT 允许等价等位置换。AD/PL 全缺失可为 null 或正确基数的全null数组，个别缺失槽位为null。没有提供的 FORMAT 不得发明。非GT字段排列、JSON键序和空白自由。

边界为1至16源、每源1至64标题样本、请求1至64样本、每个 CHROM/POS 最多32贡献记录、协调后含REF最多17种等位。REF及ALT均为非空大写 A/C/G/T/N 字符串，REF与每个ALT不相同，源ALT互不重复；REF/ALT最长32碱基。支持 REF-only 记录，ALT 字段为点时表示没有ALT。位置为1至2000000；标题中的局部字典编号不作为跨源身份。不考察符号结构变异、四倍体以上或其他 FORMAT。

只有整次输入可读取、可解析、样本存在且所有位置参考兼容时，才能成功发布。任何这类失败必须非零退出、有简短stderr且stdout为零字节，即使错误直到末尾或最后一个来源才发现。合法空源可参与；所有来源都为空时成功输出零行。对旧stdout调用，输出写入故障、磁盘不足或进程被信号终止单列运行故障，不要求回滚已经送达stdout的字节，也不要求并发或掉电恢复。对新增--out-dir文件发布，失败分类、旧版保护、并发提交和可控准备门以publication.md为准。两种模式都不要求旧ABI兼容。
