# DDI-030 v01：带权相位证据的最小撤销

一个相位项目里，不同来源的证据会相互矛盾。现在不是仅判断矛盾，而是必须在整个项目范围选出代价最低的撤销方案。

修复 `bin/phase-repair`。每项查询恰为 `id,markers,evidence,pins`：

- markers 是 1–80 个互异标识，字符规则与 id 相同。
- evidence 为 0–1200 项，每项恰为 `id,terms,parity,cost`。证据 id 在本查询内唯一。terms 为 0–6 个已声明 marker（允许重复），parity 为整数 0 或 1，cost 为整数 1–10^9；布尔值不是整数。
- pins 为对象，将部分已声明 marker 固定为整数 0 或 1。其余 marker 可自由选值。

一个证据满足，当且仅当 terms 中各 marker 的取值逐项异或等于 parity。重复出现会按异或自行抵消，空 terms 的异或为 0。每项证据独立计费；相同等式的不同 id 仍是不同证据。pins 不可撤销。

输出 `id,assignment,dropped,cost`：assignment 恰好给出全部 marker 的 0/1 整数取值且满足 pins；dropped 是**恰好所有未满足证据的 id**，按 UTF-8 字节序升序；cost 是这些证据的整数 cost 之和。要求 cost 在所有满足 pins 的 assignment 中全局最小，多个最优赋值均接受。不要求给出搜索过程或最优性证明文件。

不要把“按费用依次保留不矛盾证据”“每个冲突单独删除最便宜的一条”当成目标的定义。题目只规定这个有限整数优化问题，不附分量划分、动态规划递推或解题公式。允许使用环境中已有的优化工具；不用解决 P 与 NP 的关系。

smoke.json：三条二元 parity=1 的三角形证据，费用分别 2、3、5，无 pins。最小撤销费用为 2，一个解是 A=0、B=0、C=1，dropped=["ab"]。

## 评分

小型全局最优 0.25、重叠冲突的联合选择 0.35、多元证据及固定相位 0.25、重数与实际费用一致性 0.10、错误和输出保护 0.05。每类按实例通过比例计分。可行但非最优方案不计该实例的最优解分；不通过改变其他实例的权重追罚某一种错误。
