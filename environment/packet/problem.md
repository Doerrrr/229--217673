# DDI-032 v01：布尔极值的精确下界证书

## 任务

实现有限布尔多项式的全局极值与精确证书工具：

```bash
./bin/certified-minimum --input problems.json --output result.jsonl
```

变量 x_i 的取值为 −1 或 +1。输入给出有理系数多项式 E(x)，以及一组单项式组成的有序向量 z(x)。交出一个全局最优赋值 x*，并提交有理对称半正定矩阵 Q，使下面的恒等式在整个布尔立方体成立：

**E(x) − E(x*) = z(x)ᵀ Q z(x)，其中每个 x_i² 按 1 约化。**

正定/半正定是精确数学条件，不是“最小特征值大于 −某个误差”。不接受求解器状态、局部驻点、采样验证或有限小数误差作为全局下界证据。Q 可以不唯一；接受任何满足公开条件的证书，不与某个隐藏矩阵逐项比较。

计分的合法构造输入保证：全局最小值可由一个布尔赋值达到，且给定 basis 中存在符合下述输出长度范围的有理 Q。**不假设任意非负多项式都有低阶有理平方和证书**，不要求判断一般输入是否有这种表示。

## 输入结构

UTF-8 JSON，可带 BOM。顶层键恰为 version、queries；version 为整数 1；queries 含 1–16 个对象，id 不重复。拒绝重复 JSON 键、NaN/Infinity、缺字段和未知字段；布尔值不是整数。

query 键恰为 id、n、basis、terms：

- id：1–64 个 ASCII 字母、数字、下划线或连字符。
- n：2–32 的整数，变量下标 0…n−1。
- basis：有序的 1–65 个单项式，每个单项式为严格递增、不重复、长度 0–2 的合法下标列表；整个列表不含重复单项式，第一项必须是空列表 []，且必须包含每个单变量 [i]。除了首项，列表顺序无额外限制。空单项式表示常数 1。
- terms：1–32768 个对象，每个键恰为 vars、coef。vars 是长度 0–4 的严格递增合法下标列表；不能有重复单项式。coef 是非零有理数字符串，长度 ≤80，绝对值 ≤10¹²。terms 的顺序无语义；没有列出的系数为零。

有理数语法：可选正负号加 ASCII 十进制整数，或再跟 `/` 与一个正的 ASCII 十进制整数分母。例如 `"-3/7"`、`"5"`、`"+05/10"` 均有效；不接受小数点、指数、空白或分母零。输入不要求最简分数。输出有理数使用相同语法，字符串长度上限为 128。

terms 中的每个 vars 集合表示对应变量的乘积。注意 x_i 取值不是 0/1，重复相乘时 x_i²=1。例：x₀x₁ × x₁x₂ 在布尔域约化为 x₀x₂。输入单项式本身不允许重复下标。

## 输出结构与语义

JSONL 与 queries 顺序相同，每行键恰为 id、state、assignment、value、gram。

- CERTIFIED：assignment 为 n 个整数 −1/+1；value 为精确的 E(assignment) 有理数字符串；gram 为 m×m 的有理数字符串矩阵，m=len(basis)。要求 value 为全局最小值，且上述约化恒等式与半正定条件都成立。矩阵行列与输入 basis 顺序严格对应。
- INCUMBENT：assignment、value 同上，gram 必须为 null；没有下界证书。若该赋值恰为全局最优，仍有赋值部分分，不获得证书分。不能把 INCUMBENT 描述为已证明最优。
- UNSOLVED：assignment、value、gram 均为 null。表示本次没有给出候选，不是数学不可行证明，该实例不给数学分。

JSON 键序、空白、有理数是否约分不计分。不同最优赋值和不同合法 Gram 矩阵均接受。即使只在一项系数上相差 1/10³⁰，恒等式也不成立；即使负特征方向很小，非半正定矩阵也不是有效下界证书。

可手算例子：n=2，basis=[[],[0],[1]]，E=2−2x₀x₁。赋值 [1,1] 达到 0，矩阵 `[["0","0","0"],["0","1","-1"],["0","-1","1"]]` 为一个合法证书，因为右侧为 (x₀−x₁)²。这只说明验收语义，不是规定通用求解方法。

## 工程边界

两个 CLI 参数均必填。先校验整份输入；任一格式错误、缺参数或输入不可读时，非零退出、stderr 简短说明、stdout 为空，已有输出原字节不变。格式正确但不满足可证承诺的输入不在构造计分域；格式检查不要求预先求解优化问题。

正常完成退出 0、stdout 为空；为不存在的多层输出父目录自动建目录。输出写失败必须非零退出。允许正常返回 INCUMBENT/UNSOLVED，不得靠崩溃或挂起冒充数学失败。

提供 NumPy、SciPy、SymPy、CVXPY、SCS、Clarabel、OR-Tools 等可用依赖；允许查资料、使用成熟工具、编译和自测。不指定优化算法、Gram 搜索或精确化方法。候选可修改 app/、bin/，并增加 build.sh。Linux 容器中无需启动 Docker。

每次调用有 300 秒挂起保护和 2 GiB 容器内存。计分构造实例分别调用，支持多问题接口仍需正确。运行异常、信号终止或超时单独记录，不算有效低 T1。

## 评分

最优赋值与精确费用 0.30；二次实例的完整证书 0.15；四次实例的完整证书 0.20；秩退化/尺度混合实例的完整证书 0.25；失败处理与旧输出保护 0.10。各组按实例通过比例计分，无额外封顶。

赋值分与证书分独立记录：合法最优赋值不会因为证书缺失被扣掉已有赋值分；证书分则要求有效下界与达到该下界的赋值一起成立。全部系数恒等与半正定均精确核验，不使用浮点容差替代证明。
