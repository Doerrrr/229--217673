# RAMIFIED-ROOTS v03：二次分歧商环的规范根球与排名

实现 `/work/bench` 中 `./bin/analyze --input input.json --output result.jsonl`。在下面完全定义的有限环中，求多个一元多项式的公共根，压缩为规范的极大理想球，并按系数代表元的普通字典序回答查询。这里的未知量是一个环元素z，不是两个独立模p^k变量；固定元素pi满足pi²=p，乘法会耦合两个系数。

## 有限环的完整定义

p属于{2,3,5,7}，精度N为1—32整数。令A=p^ceil(N/2)、B=p^floor(N/2)。一个环元素的规范代表元为(a,b)，表示a+b*pi，其中0<=a<A、0<=b<B。加法按两个坐标分别相加再模A、B；乘法为：

    (a,b)*(c,d) = (a*c+p*b*d mod A, a*d+b*c mod B)

整数t嵌入为(t mod A,0)。以上运算定义全部所需语义，等价地可记pi²=p、pi^N=0。特别是奇数精度时两个坐标的模数不同；不能按两个相同模数分别做整数多项式求根，也不能把乘法替换为逐坐标相乘。精度N=1时B=1，所有规范代表元的第二坐标都是0。

## 输入

UTF-8 JSON可带BOM；顶层键恰为version、queries。version为整数1，queries含1—16个id唯一对象。拒绝重复JSON键、NaN/Infinity、缺失或未知字段，布尔值不是整数。id为1—64个ASCII字母、数字、下划线或连字符。

query键恰为id、p、precision、polynomials、ranks、boxes、values。precision即N。polynomials含1—4个多项式，每个为1—13个系数[a_i,b_i]的列表，按z的常数项到高次排列；a_i、b_i为−10^12…10^12整数，输入允许非规范系数、高次0及零多项式，按环运算归约解释。根集R是所有规范(a,b)，使每个输入多项式按上述环乘法计算都等于(0,0)。

ranks含最多32个非负整数字符串。boxes含最多32个[[alo,ahi],[blo,bhi]]闭矩形，端点用整数字符串，各轴lo<=hi，可负或超过A/B。values含最多32个[a,b]整数字符串对，询问该代表元本身是否在R；越界值为false，不先模化。输入整数字符串语法为可选ASCII正负号加十进制数字，总长度不超过80，允许前导零和正号；不接受分数、小数、空白或指数。

## 极大理想球与普通字典序

深度s球（0<=s<=N）的规范中心满足0<=r_a<p^ceil(s/2)、0<=r_b<p^floor(s/2)，其点集为：

    B(r_a,r_b,s) = { (r_a+p^ceil(s/2)*u, r_b+p^floor(s/2)*v) 在代表元范围内的全部点 }

它有p^(N−s)个点，等价于r+pi^s的倍数。s=0只有中心(0,0)，表示全环；s=N是单点。一个深度s球恰有p个深度s+1孩子：s偶数时增加a的一位p进制数字，s奇数时增加b的一位。不是每次同时增加两个坐标，也不是p²个孩子。

完整球指所有点都为共同根。只保留极大完整球，全部完整孩子必须合并为父球；计分实例保证极大球数<=4096。球数小不代表根个数小，允许大量奇异根、共同系数pi因子及作为函数恒零但系数不全为零的多项式。

按全部根的**普通(a先、b后)字典序**从0排名。这与交错的pi进制数字顺序不同，不把球列表的全部点逐球连接。

## 输出

JSONL同输入顺序，每行键恰为id、state、result。完整时state=SOLVED，result键恰为moduli、count、balls、selections、box_counts、membership。

- moduli=[A,B]，count为全部根个数。
- balls每项键恰为residues、exponent，residues=[r_a,r_b]、exponent=s；按(s,r_a数值,r_b数值)升序，无重复，恰为极大球。
- selections对应ranks，越界null，否则为[a,b]；box_counts为各矩形内R的点数；membership为各values的JSON布尔值。

moduli、count、residues、非null选择坐标及box_counts用整数值的精确有理数字符串表示，允许未约分，分母严格正；不接受小数、空白或指数。exponent为JSON整数。没有结果可UNSOLVED且result=null。

示例p=3,N=4，A=B=9，多项式z²。全部根恰为(3u,3v)，0<=u,v<3；规范球为B(0,0,2)，count=9。rank4为[3,3]。若N=5仍求z²，则完整根球为B(0,0,3)，a步长9、b步长3，体现两个坐标的深度不对称。
