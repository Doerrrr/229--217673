# DDI-031 v01：受约束 Ramsey 图补全

## 交付目标

维护一个有限图构造工具。每个输入问题要求将完全无向图的每条边染成红或蓝，并同时满足禁团、已固定边、红度数区间及红边截面计数。输出任意合法构造即可，不要求复现某个参考图。

这是有限构造任务，不要求证明 Ramsey 数的精确值、不要求解决一个开放猜想，也不要求对一般不可行问题证明不可行。计分构造输入保证存在至少一个解；格式错误输入仍须拒绝。

执行入口：

```bash
./bin/ramsey-complete --input problems.json --output result.jsonl
```

`--input`、`--output` 均必填。允许修改 app/、bin/ 和增加 build.sh；可以自行选择算法、语言或已安装求解库。没有必须使用的搜索算法。Docker 镜像提供 Python、NumPy、SciPy、OR-Tools，允许查阅资料、运行与自测。不评测输出与作者图的相似度。

## 输入

UTF-8 JSON，可带 UTF-8 BOM。顶层键恰为 `version,queries`；version 是整数 1；queries 为 1–32 个对象，同次调用的 id 唯一。JSON 的重复键、NaN/Infinity、未知字段、缺字段均为错误；布尔值不是这里的整数。

每个 query 的键恰为：

```json
{"id":"example","n":5,"red_forbid":3,"blue_forbid":3,"fixed":[],"degrees":[[0,4],[0,4],[0,4],[0,4],[0,4]],"cuts":[]}
```

- id 为 1–64 个 ASCII 字母、数字、下划线或连字符。
- n 是 5–80 的整数。顶点是 0 到 n−1，顶点编号不可改动后忽略约束。
- red_forbid、blue_forbid 分别为 3–8 的整数且不大于 n。
- fixed 是至多 n(n−1)/2 个三元组 `[u,v,c]`，满足整数 `0≤u<v<n`，c 为 0 或 1（0 蓝、1 红）。同一 `(u,v)` 不得重复，列表顺序没有语义。
- degrees 恰有 n 个 `[low,high]`，均为整数，`0≤low≤high≤n−1`；约束的是对应顶点的红边条数。
- cuts 是 0–16 个对象。每个对象的键恰为 `left,right,min,max`。left、right 各为非空、不含重复顶点的列表，二者不相交；顶点须在范围内，列表顺序无语义。min、max 为整数且 `0≤min≤max≤len(left)*len(right)`。

字段范围与结构合法、但数学上无解的输入不属于计分的承诺域；不要尝试用 UNSOLVED 证明它无解。格式检查不要求计算可解性。

## 什么算合法构造

每条无向边恰有一种颜色。红 k 团指某 k 个不同顶点之间的全部 k(k−1)/2 条边都是红色；蓝团同理。要求不存在 red_forbid 大小的红团，也不存在 blue_forbid 大小的蓝团。

fixed 中的颜色必须逐条保留。每个顶点的红度数须在给定闭区间内。每个 cut 中，从 left 到 right 的红边数须在 `[min,max]` 内；每条跨边只计一次。所有条件必须由同一张图同时满足；不能分别为禁团和计数输出不同图。

## 输出

与输入 queries 一一对应、顺序相同的 JSONL，每行键恰为 `id,state,rows`。成功构造：

```json
{"id":"example","state":"COMPLETE","rows":[".1001","1.100","01.10","001.1","1001."]}
```

rows 必须为 n 个长度 n 的字符串；主对角线仅 `.`，其他位置仅 `0`/`1`；矩阵对称。上例是红色五环，可独立核对红、蓝两色都没有三角形。输出键序和 JSON 空白不计分，允许不同的合法图。

如果没有找到构造，可以正常返回 `{"id":"example","state":"UNSOLVED","rows":null}`。它不是不可行证书，该实例不给构造分。不要靠卡死、异常或伪造成功代替这个状态。一次调用可以包含已求解和未求解的不同问题。

## 失败与运行边界

先验证整份输入；任一格式错误、缺参数、输入不可读时，非零退出，stderr 有简短原因，stdout 为空，已有 output 的原字节保持不变。正常完成退出 0，stdout 为空；自动创建不存在的多层输出父目录。输出失败必须非零退出，不得宣称成功。正常输出文件可以仅包含合法 UNSOLVED。

候选进程单次调用有 300 秒挂起保护和 2 GiB 容器内存（不是故意压缩的解题时间）。评分构造实例分别调用；工程允许一个调用处理至多 32 个问题。超时、信号终止或基础运行故障单独记录，不当作有效低 T1 的证据。不要为逐实例缓存隐藏答案；评分输入不公开。

## 得分依据

小规模完整构造 0.10；两色禁团联合构造 0.30；带固定边的补全 0.20；度数与截面耦合构造 0.30；输入失败与不覆盖旧输出 0.10。各组按该组实例通过比例计分，没有额外封顶。每个构造实例必须同时满足它的全部数学约束，不能靠矩阵外观拿构造分。

评分器会精确寻找单色禁团并重算全部计数，不随机抽查边，不信任自报统计，也不比较隐藏见证的边集。构造的规模或外观不是已证明难度；本版还没有外部模型测试成绩。
