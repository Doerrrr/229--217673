# DDI-032 平台字段

## 标题

布尔极值的精确下界证书

## 领域

数学 / 科学计算 / 优化与形式证书

## Prompt（直接粘贴）

你需要维护 `/work/certificate` 下的布尔多项式极值与精确下界证书工具。
请完整阅读工程中的 `packet/problem.md`，按其公开的输入、输出、数学和失败保护契约，
修复 `app/` 与 `bin/`，必要时新增 `build.sh`。

统一入口为 `./bin/certified-minimum --input problems.json --output result.jsonl`。
交付全局最优布尔赋值以及精确有理半正定 Gram 下界证书；允许不同的合法赋值和证书。
只找到候选时应如实返回 `INCUMBENT`，没有候选时返回 `UNSOLVED`。
浮点数值容差、局部最优或求解器打印的状态不能替代精确证书。

允许查资料、使用镜像中现有的优化库、编译、运行和自测。已处于 Linux 容器中，
不需要启动嵌套 Docker。请直接修改工作目录中的源码，平台将运行工程判分，不要求另外打包答卷。

## 测试说明

测试按公开规则独立核验最优赋值、精确系数恒等式、精确半正定条件、
多问题输出顺序、输入校验及失败时已有输出字节保护。
接受任意满足规则的赋值和证书，不比较作者的固定 Gram 矩阵。
评分保持五类权重 0.30 / 0.15 / 0.20 / 0.25 / 0.10，组内按实例比例计分，无额外封顶。
