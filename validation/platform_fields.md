# 平台介绍字段（第三版）

## Prompt

本题要求模型修复一个面向药物相互作用研究的防泄漏训练数据发布工具。
输入包含药物 SMILES、事件类型说明和有向相互作用三份 CSV。模型首先需
依据 RDKit 分子身份进行规范化、别名合并、冲突隔离和有向去重，再将
Murcko scaffold 等价关系与 Morgan 指纹相似关系取连通闭包，形成不可
跨训练、验证与测试折的化学簇。发布时只保留同折正例，并为验证和测试
目标生成排除双向已知正例的未观测候选对。候选分配必须全局优化匹配
数量、总相似度整数分数及字典序，不允许独立贪心。最终交付三个 CSV
及完整 JSON 报告，满足确定性、计数守恒和致命输入错误不覆盖旧输出。
未观测候选不被宣称为已证实的生物学阴性。

## 环境思路

采用 Python 3.11 的 Linux 容器，固定 RDKit 2025.3.6，仅安装计算所需
依赖。环境包含三份原始研究数据和可运行但不完整的 ddi-release 草稿。
草稿混淆 ID 与分子、丢失方向、错误分折且缺少候选匹配阶段。模型需
根据公开契约修复 /usr/local/bin/ddi-release 及 /opt/ddi-release 下的实现；
判题会用不同路径重跑。题面完整规定 CSV、化学图、分折、候选过滤、
最优化顺序和报告结构，不依赖隐藏配置或故意缩短时限。

## 测试思路

按业务交付分六类评分：精确匹配 0.35、化学分簇分折 0.20、候选安全性
与分数 0.15、正例分区 0.10、基础清洗 0.10、确定性与失败保护 0.10。
15 项测试覆盖传递相似性、scaffold 等价、手性、别名、冲突拒绝、反向
及其他事件已知正例、top-8、候选容量、贪心反例和字典序决胜。小图
通过穷举独立核算；全量数据核对守恒摘要和 CSV SHA-256。验证器使用
独立图遍历与 Hungarian 算法，不导入参考解。致命错误测试在四份旧
输出放置哨兵字节后重跑，验证它们完全不变。另用四种不完整实现作
负对照，证实核心错误可以被检出；平台实际 T1 分数须单独测量。

## 参考解思路

先完整读取并校验输入，再隔离冲突 ID/事件，规范化分子与有向三元组。
使用 RDKit Murcko scaffold 和含手性的 Morgan 位指纹建立化学关系，
用并查集取闭包并以簇内最小 SMILES 的 SHA-256 决定分折。按锚点轮转
选择目标，依据全部清洗正例进行双向过滤，计算整数相似度分数并截取
top-8。每折构造精确残量最小费用流，用可证明优先级的整数费用编码
匹配数、总分和候选 ID 序列，允许重分配而非贪心。最后渲染四份输出
并写入实际 CSV 字节的 SHA-256。所有输入致命错误在替换任何旧输出
之前发现。参考优化器和验证器分别经 500 个小图穷举对照。
