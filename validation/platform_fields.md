# 平台介绍字段（第四版，分别直接粘贴）

## Prompt

本题要求模型修复一个面向药物相互作用研究的防泄漏候选实验发布工具。输入为药物结构、事件类型、有向相互作用三份 CSV，以及公开定义的实验资源计划。模型须先完成分子规范化、别名合并、冲突隔离和有向去重，再对 Murcko scaffold 与 Morgan 指纹相似关系取连通闭包，以化学簇固定训练、验证和测试折。在安全 top-8 候选范围内，联合决定哪些目标和候选进入实验批次，满足锚点与候选共享库存、每个药物只付一次准备费用、总预算、候选簇上限及事件覆盖配额。优化顺序为实验数量最多、整数相似度总分最高、实际费用最低、候选 ID 序列字典序最小。格式合法但无解的计划必须明确报告 INFEASIBLE，不可放宽配额。最终交付三个 CSV 和完整 JSON 审计报告，保证确定性、守恒和致命错误不覆盖旧输出。未观测候选对不被称为已证实的生物学阴性。

## 环境思路

采用 Python 3.11 Linux 容器，锁定 RDKit 2025.3.6、OR-Tools 9.14.6206、SciPy 1.15.3，分别用于化学计算和精确优化。候选环境仅包含三份原始数据、screen_plan.json 和可运行但不完整的 ddi-release 草稿，没有隐藏参考解或评分期望。草稿接受五个必填参数，但混淆分子身份、丢失方向、错误分折且缺少资源规划。题面公开全部 CSV 和严格 JSON 契约、整数范围、别名覆盖合并规则、四层最优顺序及报告字段；判题会用不同输入路径重跑。agent 时限保持 2400 秒，verifier 为 600 秒，不依靠缺依赖、超时或环境失败制造难度。

## 测试思路

保持 15 项检查及六类权重：联合精确优化 0.35、化学分簇分折 0.20、候选安全性/分数与可执行性 0.15、正例分区 0.10、基础清洗 0.10、确定性与失败保护 0.10。评分器独立构建 SciPy MILP，不导入参考实现。小型化学样例具有人工核算的目标、候选和资源账目，覆盖共享角色库存、别名不增加库存、准备费用只计一次、预算等值边界、事件覆盖、簇上限及数量/分数/费用/字典序四层决胜；500 个小实例另与穷举对照。完整数据固定摘要及 CSV 哈希，分子表和正例表延续第三版。错误计划、缺参数和 CSV 错误使用四份旧输出哨兵验证不覆盖。检查精确 0.15 相似度边界、BOM、跨物理行、转义、空结果与不可行计划。负对照实际运行忽略计划、匹配后裁剪、分角色计库存、重复收准备费、忽略事件下限及浮点扰动字典序的错误实现；发现核心业务偏差即判对应检查失败。发布前做候选/隐藏文件重复预检及三次冷运行时限核验。负对照分数不是模型 T1 预测。

## 参考解思路

先完整读取 CSV 并完成药物、事件及交互清洗，再严格校验计划对象、重复 JSON 键、整数范围、有效药物别名与事件引用。用 RDKit 含手性 Morgan 位指纹和 Murcko scaffold 建图，并查集计算连通分簇和固定分折。按锚点轮转选目标，排除任一方向任一事件的已知正例，生成安全 top-8。每折构建 OR-Tools CP-SAT：边变量表示实验选择，药物激活变量表示一次准备；库存合并锚点和候选角色，另加预算、数量、候选簇和事件配额约束。依次证明并固定最大数量、最高整数总分、最低实际费用，再逐目标固定最小 ID 选择，不使用巨大浮点字典序权重。不可行时全体 UNMATCHED、零费用和零消耗；可行空结果标为 OPTIMAL。最后渲染三份 CSV、资源审计及实际文件 SHA-256，任何致命输入错误均在替换旧输出之前发现。参考脚本只安装 Python 实现，复用候选环境已有入口。
