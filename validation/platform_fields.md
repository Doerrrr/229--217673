# 新版平台介绍（待盲测审计完成后使用）

## Prompt

本题围绕生物信息学训练数据的连续清洗与可靠发布展开。模型需要修复已部署的药物相互作用预处理程序，读取药物结构、事件字典、有向相互作用及三份有序变更文件，使用 RDKit 规范化分子，隔离冲突，完成原始记录回放，并按化学结构而非代表 ID 计算真实语义增删。在此基础上，多个作业可能竞争同一个旧版本，训练读者必须始终读取完整的一代数据。模型还须实现不可变发布目录、预期父版本比较、请求身份去重、无锁快照读取，以及异常和进程中断后的安全重试，避免把未提交版本误当成功或把当前版本回滚。最终交付是可运行的清洗命令与发布模块，而非静态填充输出文件。

## 环境思路

使用 Python 3.11 slim Linux 容器并锁定 RDKit 2025.3.6。候选环境只包含两个待修 Python 模块、命令入口及既有六份 CSV 输入，不包含参考实现、隐藏测试或固定输出。发布任务使用标准库和本地文件系统语义，不要求新增数据库或重型优化依赖。保留平铺清洗模式，并用一对参数启用不可变代际发布模式。初始程序可解析参数，但清洗和发布状态管理均不完整。所有规范、API、文件格式和故障回调在题面公开。

## 测试思路

保留 14 项清洗、增量回放、方向去重、拒绝优先级、语义差异和全量摘要检查，总计 0.55；另以五项独立责任验证发布交付、并发比较交换、请求身份与祖先重试、异常及进程终止恢复、参数和完整性边界，总计 0.45，无单项失败封顶。可信父进程独立读取指针、清单和文件字节，候选代码在非特权子进程执行；诊断输出与控制协议分开。并发和故障探针通过公开回调暂停或终止作业，再用新进程实际重试，不能仅检查错误提示。原始完整数据的清洗 CSV 哈希保持不变。

## 参考解思路

先完整读取并验证六份输入，对基线与回放后的原始快照分别清洗，以规范异构 SMILES 和数字事件类型比较有向相互作用身份，生成四份确定性字节产物。发布器校验请求后取得稳定写锁，再核对当前父链及已有发布身份；对真正的新请求写入临时完整目录，持久化并封存后只原子切换一个 CURRENT 指针。已提交祖先的重试不重复执行也不回滚，未提交封存目录须在父版本仍匹配时才能恢复。读取端只捕获一次 CURRENT，再核验不可变产物清单。指针切换前后异常遵循不同但明确的恢复边界。
