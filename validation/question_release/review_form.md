# 环状DNA背景库的双核苷酸约束去重与周期谱

主标签：D.4 生物信息学。可附选H.1 数学问题、C.1 数据处理。

## Prompt

本题围绕生物序列富集分析中的背景库审计，修复一个保留双核苷酸计数的环状DNA统计工具。旧程序仅按碱基总量计算排列数，再除以序列长度和2，忽略了闭环相邻关系、重复周期及自反向互补分子的特殊情况。模型需要根据给定的4×4有向双核苷酸计数矩阵，精确计算带起点字符串数、旋转去重类数、旋转与反向互补共同去重的双链类数，并按最小周期输出完整分类。任务明确统计池由原矩阵与反向互补矩阵对应的字符串集合取并集，要求正确处理两个集合相同或不相交的情况。核心考查是将序列约束、不可区分的重复相邻对及群作用稳定子联系起来，完成可在规定资源内运行的通用精确算法，而不是依靠小规模枚举、简单整除或抽样近似。

## 环境相关思路

使用固定摘要的Python 3.11.17 slim基础镜像，运行环境为Linux、2个CPU和2048MiB内存，单次候选命令设置300秒保护。参考实现和已有工程只依赖Python标准库，不需要安装科学计算框架、数据库、GPU工具或额外云服务，也不需要在题目容器内启动Docker。工程工作目录为/work/bench，app目录包含旧估计器及输入输出支持代码，bin/analyze为统一命令入口，packet目录提供完整数学契约和公开样例。Dockerfile只复制公开工程，不包含私有评分器、隐藏数据或参考解；作者参考实现通过solution/solve.sh安装，测试由Harbor验证阶段运行。输入校验、批量查询顺序、多层输出目录和原子替换均有明确工程约定。本地镜像直接由提交Dockerfile构建，避免使用额外依赖更丰富的替代环境证明通过。

## 测试相关思路

生产测试直接执行候选命令，并对24组计数矩阵的精确结果分组判分。带起点数量、旋转类总数、双链类总数、完整周期谱及工程行为分别占0.10、0.10、0.25、0.50和0.05，各组按实例通过比例计分。矩阵覆盖反向互补对称与非对称、重复周期、存在或不存在自反向互补类、不同支持字母及较大计数，另检查度不平衡、支持图断开和单碱基等合法边界。完整结果只接受SOLVED，PARTIAL不能获得数学分；公开示例不进入加权数学用例。工程测试覆盖非法JSON、重复键、布尔值冒充整数、参数缺失、两条及16条查询的批量顺序、17条超限输入拒绝、已有输出成功替换和失败时旧输出保护。验证副本采用不跟随链接的目录描述符复制，拒绝符号链接、硬链接和特殊节点；在复制完成并检查安全后才按原流程移交UID10001。作者另以短字符串穷举和显式旋转/反向互补作用独立核验参考算法。R1安全返修后本地Oracle为1.000，NOP为0.038889；正式平台候选模型的结果需针对实际提交版本另行取得。

## 参考解相关思路

参考解首先把双核苷酸矩阵看作有向多重图的边计数，检查闭环可实现性，并通过有向矩阵树计数和Euler路径组合公式计算字符串数量，同时除去相同双核苷酸边被重复编号造成的排列重数。随后按长度约数逐层消去较短周期的贡献，得到每个最小周期的本原字符串数和旋转类数。对于反向互补不对称的矩阵，两个方向的字符串集合互不相交，旋转类按反向互补成对合并；对于对称矩阵，进一步把反向互补反射固定点分解成半路径及两个边界连接，精确累计其固定点数，再剔除较短周期贡献，求出自反向互补旋转类及双链类。所有运算使用任意精度整数，合法但无闭环实现时返回零统计。该参考解是通用计算算法，没有按测试实例登记答案或有限见证表。
